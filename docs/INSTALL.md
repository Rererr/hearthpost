# hearthpost の入れ方（パソコンに詳しくない方向け）

[English](INSTALL.en.md)

この手順書は、hearthpost を家のパソコンに入れて、ファイルを送れるようになるまでを案内します。
コマンドの入力やプログラミングの知識は要りません。
1 台あたり 10 分ほどかかります。

最初に「用意するもの」と「ダウンロードする」を読み、そのあと自分のパソコンの章（Mac か Windows）だけを読んでください。
入れ終わったら「はじめて送ってみる」に進みます。
うまくいかないときは、最後の「困ったとき」から近いものを探してください。

## 用意するもの

- hearthpost を入れるパソコン 2 台以上（Mac どうし、Windows どうし、Mac と Windows のどれでも送り合えます）
- 2 台とも同じ家の Wi-Fi（または同じルーター）につながっていること
- Mac は macOS 10.13 以降、Windows は Windows 10 か 11

hearthpost は家の中のネットワークだけで動きます。
送ったファイルがインターネットやクラウドに出ることはありません。
そのかわり、外出先と家のように別々のネットワークにいるパソコンどうしでは送れません。

## ダウンロードする

次のページを開き、一番上に出ている版から、自分のパソコンに合うファイルをクリックしてダウンロードします。

https://github.com/Rererr/hearthpost/releases

| パソコン | ダウンロードするファイル |
|---|---|
| Mac | `hearthpost-mac.dmg` |
| Windows | `hearthpost-windows-setup.exe` |

その版の下のほうの「Assets」という欄に並んでいます。
「Source code」と書かれたファイルは開発者向けなので、ダウンロードしなくてかまいません。

## Mac に入れる

### 1. アプリを「アプリケーション」フォルダに移す

1. Finder で「ダウンロード」フォルダを開き、`hearthpost-mac.dmg` をダブルクリックします。
2. 「hearthpost」のアイコンと「Applications」のフォルダが並んだ画面が開きます。「hearthpost」を「Applications」の上へドラッグします。
3. 終わったら、Finder の左側に出ている「hearthpost」の横の取り出しボタン（⏏）を押して閉じます。ダウンロードした `hearthpost-mac.dmg` は、もう捨ててかまいません。

### 2. 初めて開く

hearthpost には Apple の審査済みの署名がありません（個人が無料で公開しているアプリのため）。
そのため、初めて開くときだけ、Mac に「開いてよい」と伝える操作が要ります。

1. 「アプリケーション」フォルダの「hearthpost」をダブルクリックします。
2. 「Apple は、“hearthpost.app”に Mac に損害を与えたり、プライバシーを侵害する可能性のあるマルウェアが含まれていないことを検証できませんでした。」と出たら、「完了」を押して閉じます（ここで「ゴミ箱に入れる」は押さないでください）。署名のないアプリにはいつも出る表示で、hearthpost が壊れているわけではありません。この画面には開くボタンがないので、続けて次の 3 の操作をします。
3. 画面左上のりんごのマークから「システム設定」を開き、左の一覧で「プライバシーとセキュリティ」を選びます。
4. 右側を下までスクロールすると、「セキュリティ」の欄に hearthpost についての案内と「このまま開く」ボタンがあります。これを押します。このボタンは、開こうとしてから 1 時間ほどしか出ません。見当たらないときは、もう一度 1 と 2 をしてから戻ってきてください。
5. もう一度確認が出たら「このまま開く」を押し、Mac のパスワード（または指紋）を入れます。

これで hearthpost の画面が開きます。
2 回目からは、ふつうにダブルクリックするだけで開きます。

メッセージの文言やボタンの名前は、macOS のバージョンによって少し違います。
macOS 14 以前では、「hearthpost」を control キーを押しながらクリックして「開く」を選ぶ方法でも開けます。

### 3. 出てくる確認に「許可」で答える

開いたあと、次の 2 つの確認が出ます（ファイアウォールを切っている Mac では 2 つ目は出ません）。
どちらも hearthpost が家の中のパソコンと話すために必要なので、「許可」を押してください。

- 「“hearthpost”がローカルネットワーク上のデバイスを検出して接続することを求めています」 → 「許可」
- 「アプリケーション“hearthpost”へのネットワーク受信接続を許可しますか？」 → 「許可」

ここで「許可しない」や「拒否」を押すと、相手が見つからなかったり、受け取れなかったりします。
押してしまったときは「困ったとき」の「相手から送ってもらっても何も届かない」を見てください。

## Windows に入れる

### 1. インストーラーを開く

1. エクスプローラーで「ダウンロード」フォルダを開き、`hearthpost-windows-setup.exe` をダブルクリックします。
2. 「Windows によって PC が保護されました」という画面が出たら、「詳細情報」を押し、出てきた「実行」を押します。

この画面は、Microsoft の審査済みの署名がないアプリで出ます（個人が無料で公開しているアプリのため）。

### 2. 画面の案内どおりに進める

1. 「hearthpost セットアップへようこそ」で「次へ」を押します。
2. 「インストール先の選択」は変えずに「インストール」を押します。
3. 「hearthpost セットアップの完了」で「hearthpost を実行」にチェックが入っていることを確かめ、「完了」を押します。

hearthpost が開きます。
デスクトップとスタートメニューに hearthpost のアイコンができるので、次からはそこから開きます。
パソコンの管理者のパスワードは要りません（いま使っている Windows のユーザーにだけ入ります）。

### 3. ファイアウォールの確認に「許可」で答える

「Windows セキュリティの重要な警告」という画面が出たら、次のようにします。

1. 「プライベート ネットワーク」にチェックが入っていることを確かめます。
2. 「パブリック ネットワーク」のチェックは外したままでかまいません。
3. 「アクセスを許可する」を押します。

この画面が出ないまま閉じてしまったときや、「キャンセル」を押したときは、「困ったとき」の「相手から送ってもらっても何も届かない」を見てください。

### 4. 家の Wi-Fi を「プライベート」にする

Windows は、つないでいる Wi-Fi が「パブリック」になっていると、ほかのパソコンからの接続を止めます。
家の Wi-Fi なら「プライベート」にしておきます。

1. スタートボタンから「設定」を開き、「ネットワークとインターネット」を選びます。
2. 「Wi-Fi」（有線なら「イーサネット」）を選び、いまつないでいるネットワークの名前を押します。
3. 「ネットワーク プロファイルの種類」で「プライベート ネットワーク」を選びます。

カフェや駅などの Wi-Fi は「パブリック」のままにしておいてください。

## はじめて送ってみる

### 自分のパソコンの名前を決める

hearthpost の画面の上部に、このパソコンの名前が出ています。
名前の横の「変更」を押すと変えられるので、「お父さんの Mac」「リビングの Windows」のように、家族が見て分かる名前にしておくと便利です。

### 相手が「送り先」に出るまで待つ

送りたい相手のパソコンでも hearthpost を開いておきます。
数秒すると、画面の「送り先」に相手の名前のカードが並びます。

### ファイルを送る

送り先のカードにファイルをドラッグして離すと送ります。
カードの「ファイル」「フォルダ」「テキスト」のボタンを押して選んでもかまいません。

### 受け取る側で確認コードを見比べる

受け取る側の画面に、「（送った人のパソコンの名前） から届いています」という確認と、6 桁の数字（確認コード）が出ます。
送った側の画面にも同じ数字が出ているので、2 台の数字が同じかどうか見比べてください。
同じなら「受け取る」を押します。
違うときは、別のパソコンが割り込んでいる可能性があるので「断る」を押してください。

### 受け取ったファイルを開く

受け取ったファイルは「ダウンロード」フォルダに入ります。
画面上部の「保存先」で場所を変えたり、「開く」でそのフォルダを開いたりできます。
送り先に同じ名前のファイルがあっても上書きはせず、「名前 (1)」のように番号を付けて保存します。

### 家族のパソコンどうしは「ペアリング」しておく

毎回「受け取る」を押すのが面倒な相手とは、ペアリングしておくと確認なしで受け取れるようになります。

1. 相手のカードの「ペアリング」を押します。
2. 2 台の画面に出る 6 桁の数字が同じか見比べます。
3. 同じなら、自分の画面で「同じ数字です」を押し、相手の画面では「ペアリングする」を押してもらいます。

ペアリングは、家族のパソコンなど信頼できる相手とだけしてください。
やめたいときは、カードの「解除」を押します（解除はそのパソコンにだけ効くので、相手の画面でも解除してもらってください）。

## 困ったとき

### 相手が「送り先」に出てこない

- 2 台が同じ Wi-Fi につながっているか確かめてください。同じ家でも、ルーターに「ゲスト用」の Wi-Fi があると、そちらにつないだパソコンとは送り合えません。
- Windows では、上の「家の Wi-Fi を『プライベート』にする」を確かめてください。
- VPN のアプリを使っているときは、いったん切ってください。
- それでも出てこないときは、相手の画面の上部に「IP:」に続けて出ている数字（例: `192.168.1.23`）を、自分の画面の「IP アドレスで追加」の欄に入れて「追加」を押してください。

### 相手から送ってもらっても何も届かない

初めて開いたときの確認で「許可しない」「拒否」「キャンセル」のどれかを押した可能性があります。

- Mac: 「システム設定」→「ネットワーク」→「ファイアウォール」→「オプション」で hearthpost を「受信接続を許可」にします。あわせて「システム設定」→「プライバシーとセキュリティ」→「ローカルネットワーク」で hearthpost をオンにします。
- Windows: スタートボタンから「Windows セキュリティ」を開き、「ファイアウォールとネットワーク保護」→「ファイアウォールによるアプリケーションの許可」→「設定の変更」で、hearthpost の「プライベート」にチェックを入れます。

直したら、hearthpost を一度終了して開き直してください。

### Mac で「保存先に書き込めません」と出る

保存先を「書類」や「デスクトップ」にしていると、Mac がアクセスを止めていることがあります。
「システム設定」→「プライバシーとセキュリティ」→「ファイルとフォルダ」で hearthpost を許可するか、保存先を「ダウンロード」に戻してください。

この手順書で解決しないときは、次のページの「New issue」から日本語で質問してください（GitHub のアカウントが要ります）。

https://github.com/Rererr/hearthpost/issues

## やめるとき（アンインストール）

- Mac: 「アプリケーション」フォルダの「hearthpost」をゴミ箱に入れます。
- Windows: スタートボタンから「設定」→「アプリ」→「インストールされているアプリ」を開き、hearthpost の横の「…」から「アンインストール」を選びます（Windows 10 では「設定」→「アプリ」→「アプリと機能」）。

受け取ったファイルは保存先に残ります。
ペアリングした相手などの設定も消したいときは、次のフォルダも削除してください。

- Mac: Finder の「移動」メニュー →「フォルダへ移動」に `~/Library/Application Support/hearthpost` と入れて開いたフォルダ
- Windows: エクスプローラーのアドレス欄に `%AppData%\hearthpost` と入れて開いたフォルダ
